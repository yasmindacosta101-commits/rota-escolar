# Documento de Requisitos — Rota Escolar

O **Rota Escolar** é um sistema para auxiliar uma escola de médio porte no controle do transporte escolar de crianças do **1º ao 5º ano do Ensino Fundamental**.

O sistema terá como foco a organização das rotas, dos pontos de embarque e dos alunos que utilizam o transporte escolar.

## 2. Objetivo

O sistema tem como objetivo facilitar a organização do transporte escolar, ajudando a escola e os motoristas a controlarem as rotas e os embarques dos alunos.

## 3. Usuários do sistema

### 3.1 Escola

A escola será responsável pelo cadastro e organização das informações do transporte escolar.

### 3.2 Motorista

O motorista poderá consultar sua rota, visualizar os alunos de cada ponto e registrar os embarques.

## 4. Requisitos funcionais

### RF01 — Cadastro de alunos

O sistema deverá permitir que a escola cadastre os alunos que utilizam o transporte escolar.

### RF02 — Cadastro de motoristas

O sistema deverá permitir que a escola cadastre os motoristas responsáveis pelas rotas.

### RF03 — Cadastro de rotas

O sistema deverá permitir que a escola cadastre e organize as rotas do transporte escolar.

### RF04 — Cadastro de pontos de embarque

O sistema deverá permitir que a escola cadastre os pontos de embarque de cada rota.

### RF05 — Associação de alunos

O sistema deverá permitir que a escola associe cada aluno a uma rota e a um ponto de embarque.

### RF06 — Consulta da rota

O sistema deverá permitir que o motorista visualize sua rota e os respectivos pontos de embarque.

### RF07 — Consulta dos alunos

O sistema deverá permitir que o motorista visualize os alunos que devem embarcar em cada ponto.

### RF08 — Registro de embarque

O sistema deverá permitir que o motorista registre se o aluno embarcou ou não.

## 5. Requisitos não funcionais

### RNF01 — Facilidade de uso

O sistema deverá possuir uma interface simples e fácil de utilizar.

### RNF02 — Organização

As informações de alunos, rotas e pontos de embarque deverão ser apresentadas de forma organizada.

O sistema terá como foco:

- Cadastro de alunos;
- Cadastro de rotas;
- Cadastro de pontos de embarque;
- Associação de alunos às rotas;
- Consulta das rotas;
- Consulta dos alunos por ponto;
- Registro de embarque.

O **Rota Escolar** busca facilitar a organização do transporte escolar, ajudando a escola e os motoristas a controlarem as rotas e os embarques dos alunos.
