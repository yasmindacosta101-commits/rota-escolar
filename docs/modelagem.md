# Modelagem da Solução — Rota Escolar

## Objetivo

Esta modelagem apresenta o funcionamento inicial do sistema Rota Escolar, demonstrando o fluxo principal relacionado à consulta das rotas, dos pontos de embarque e ao registro dos alunos.

## Fluxo principal

O funcionamento principal do sistema segue as etapas:

1. Acessar o sistema;
2. Selecionar uma rota;
3. Visualizar os pontos de embarque;
4. Visualizar os alunos de cada ponto;
5. Registrar se o aluno embarcou ou não;
6. Verificar se existem mais pontos na rota;
7. Continuar o processo ou finalizar a rota.

## Elementos principais

A solução possui como principais elementos:

- Aluno;
- Motorista;
- Rota;
- Ponto de embarque;
- Registro de embarque.

O aluno está associado a uma rota e a um ponto de embarque. O motorista consulta a rota e visualiza os alunos previstos em cada ponto, podendo registrar o embarque ou não embarque.
